# Análisis de ventas de cuatro tiendas

Este proyecto contiene un análisis de datos de ventas provenientes de cuatro tiendas. El objetivo es identificar cuál de las tiendas es la mejor opción para vender, basándose en diferentes métricas y visualizaciones.

## 📊 Objetivos del análisis

- Calcular la facturación total por tienda.
- Identificar las categorías más vendidas.
- Evaluar las reseñas y calificaciones de los clientes.
- Analizar los productos más vendidos.
- Calcular el costo de envío promedio por tienda.
- Realizar una recomendación de tienda basada en datos.

## 🛒 Datos analizados

Los datos utilizados incluyen información como:

- Nombre del producto
- Precio
- Categoría
- Calificación del cliente
- Costo de envío
- Vendedor
- Fecha de compra
- Ubicación de la compra

## 🧠 Herramientas utilizadas

- **Python**
- **Google Colab**
- Librerías:
  - `pandas`
  - `matplotlib`
  

## 📈 Visualizaciones

Se generaron gráficos para facilitar la interpretación de los datos, incluyendo:

- Ingresos por tienda
- Categorías más vendidas
- Calificaciones de clientes
- Costos de envío por tienda

## 📝 Conclusión

Al finalizar el análisis, se realiza una recomendación sobre  qué tienda conviene vender , con base en los datos explorados.

## 🚀 Cómo usar este repositorio

1. Clona el repositorio o descarga los archivos.
2. Abre el archivo `proyecto_1_ventas.ipynb` en Google Colab o Jupyter Notebook.
3. Asegúrate de tener los archivos CSV dentro de la carpeta `datos/`.
4. Ejecuta el notebook para explorar el análisis.
